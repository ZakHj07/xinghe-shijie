# 星河视界 · Gesture Universe

**▶ 在线体验：[cute-croquembouche-ce36b4.netlify.app](https://cute-croquembouche-ce36b4.netlify.app)** ・ [GitHub 仓库](https://github.com/ZakHj07/xinghe-shijie)

一个用鼠标 / 摄像头手势漫游的三维宇宙场景：**粒子银河系 → 太阳系 → 地球 → 回到银河系**。

全部用 Three.js（r170）+ MediaPipe Hand Landmarker 手写实现，无构建步骤，双击 `start.bat` 即可打开。

[![粒子银河系](docs/galaxy.jpg)](https://cute-croquembouche-ce36b4.netlify.app)

<img src="docs/solar.jpg" width="49.6%" alt="太阳系"> <img src="docs/earth.jpg" width="49.6%" alt="地球">

> 张开手掌放大推进 → 穿过猎户臂进入太阳系 → 俯冲地球；握拳缩小，一路退回银河。全程可用手势或鼠标 / 滚轮。

---

## 开始

```bat
start.bat
```

它会在本机 8123 端口起一个静态服务器并打开 http://127.0.0.1:8123/ 。

> 必须走 HTTP 打开（`file://` 会因为 ES module 与模型跨域限制失败）。
> `start.bat` 会优先用 `node`，找不到时用 DSH 自带的 Node 运行时；
> 也可以自己 `python -m http.server` —— 但 Windows 的 Python 会把 `.mjs`、`.task` 当 `text/plain`，浏览器会拒绝加载，这也是仓库里带了一个小 `server.mjs` 的原因。

想分享给朋友，看 [`SHARE.md`](SHARE.md)：同一 WiFi 用 `start-lan.bat`（只能鼠标），要完整体验就把 `share.bat` 生成的 `dist\` 拖到静态托管拿一个 https 链接。

点「进入宇宙」= 请求摄像头权限 + 加载手势模型；不给摄像头权限也能玩，会退化成鼠标模式。

## 操作

| 场景 | 手势 | 鼠标 / 键盘 |
| --- | --- | --- |
| 银河系 | 张开手掌 = 放大推进；握拳 = 缩小；左右移动手掌 = 转动视角 | 拖拽旋转、滚轮缩放、`1` `2` `3` 直接跳场景 |
| 太阳系 | 张开手掌 = 再放大 → 飞向地球；手掌上下左右移动 = 改变观察角度 | 同上 |
| 地球 | 手掌任意方向移动 = 转动地球（可 360° 自由转，转过去背景行星会跟着移位）；握拳 = 缩小 → 回到银河系 | 拖拽转动地球、滚轮缩放 |

放大到极限（银河、太阳系）或缩小到极限（地球）会触发一段「跃迁」过渡动画。

左下角是场景导航：`01 银河系 / 02 太阳系 / 03 地球` 三个按钮，点一下直接跳过去，当前场景高亮；转场进行中这条导航会变淡并锁住点击，避免连点把状态机打断。键盘 `1` `2` `3` 等价于这三个按钮。

右下角两枚圆形按钮：上面是**全屏**（四角括号图标，进全屏后变成四角内收，点击或按 `F` 切换，`Esc` 由浏览器接管退出），下面是**背景音乐**开关（三根跳动的竖条，静音后变灰静止）。全屏按钮走的是 `requestFullscreen`，被嵌入或策略拒绝时会静默保持原状，不会弹错。

## 三个场景各自做了什么

**银河系** `js/scenes/galaxy.js`
- 13 万粒子：9% 核球高斯分布 + 两条对数螺旋臂，HII 恒星形成区染成粉色
- 顶点着色器里做差速自转（内圈快、外圈慢）与闪烁，着色器内旋转 → 零 CPU 开销
- 银盘相对相机倾斜 58°，形成 M51 那种斜视角
- 背景：程序化星云天穹。噪声先做一层域扭曲再采样，出来是**纤维/丝状**而不是一团团糊斑；尘埃带的朝向由 `uPlane`（银盘法线，每帧跟着 `galaxyGroup` 更新）决定，所以背景光带永远和银盘共面，两者不会各走各的；配色只取深海军蓝 + 冷青 + 一点点暖褐，避开和主体抢眼的紫色
- 远景星：5600 颗，片元是「锐利小核 + 很淡的晕」，只有最亮的几颗带十字衍射；靠近时点尺寸会变大，但粒子亮度与泛光同步收窄（`uDim` + `bloomScale`），避免钻进银河时整屏发白
- **流沙星河**（铺满整个天空）：两层尘埃点，都挂在 `scene` 而不是 `galaxyGroup` 上 —— 它们是「宇宙的背景」，不管视角转到哪、镜头拉到多近，四角都有细沙在缓慢流动。
  - 远景层 30000 颗，r=900–2900，几乎不动（0.004–0.012 rad/s），负责天空的颗粒感
  - 近景层 16000 颗，r=190–640，转速快 3–5 倍（0.02–0.06 rad/s），镜头一动就拖出「流沙」的流向
  - 两层都用 Rodrigues 公式绕一根倾斜轴（`uAxis = (0.18, 1.0, 0.24)`）做**差速**旋转，角速度按 `1/sqrt(r/rMin)` 衰减：内圈快、外圈慢；42% / 34% 的点贴着一条倾斜大圆分布，形成带状而不是均匀的点阵
  - 亮度克制：叠加后整帧平均亮度只比没有这层时高 1.2/255；`uGain` 只在俯冲时抬到 1.55 增加一点速度感
  - **不参与进场动画**：银河本体与四个邻居是从中心 `scale(0.06→1)` 长出来的，尘埃层从头就在，进场时背景已经是满天细沙
- **邻近星系**：背景里还有四团真实存在的邻居，各自由几千颗粒子按各自的形态生成，并且**一边自转一边沿一条极缓的轨道漂移**（`rotation.y += dt*spin` 叠 `pivot` 绕银心的 `orbitSpeed`），所以静止看几十秒也能察觉它们在动——
  - **仙女座 M31**（左上，9000 粒）：14% 核球 + 两条对数旋臂，盘面倾斜 41°，暖白核 + 冷蓝臂，另挂 M32 / M110 两颗小卫星
  - **大麦哲伦云 LMC**（左下，4200 粒）：棒状核心 + 一条残臂 + 5% 粉色星暴区（塔兰图拉那种颜色）
  - **小麦哲伦云 SMC**（右下，1900 粒）：两团高斯叠加的不规则矮星系
  - **三角座 M33**（右上，2600 粒）：松散的小旋涡，负责补一点纵深
  - 参数在 `js/scenes/galaxy.js` 的 `addCompanion(...)`：`pos` 定方位、`tiltX/tiltZ` 定盘面朝向、`spin` 自转、`orbitSpeed` 漂移、`bob` 上下浮动；`uBright` 统一压到 0.26–0.34，否则跟主体银河抢亮度
  - 名字标签走 `state.anchors` → `main.js` 的 `buildLabels()/updateLabels()`：每帧把锚点投影成屏幕坐标，衬线小字 + 一条渐隐竖线，靠画面边缘自动淡出；只在银河场景且进场动画结束、没有转场时出现

**太阳系** `js/scenes/solar.js`
- 太阳系里继续拉近时，镜头会从「朝太阳推」转成「朝地球靠」，地球长到约三分之一屏高（`earthFrac() >= 0.30`）才自动接管太阳系→地球的转场
- 深空邻居 `js/scenes/deepfield.js`：环绕银河的三层星云与星系精灵（发射星云 / 反射星云 / 暗星云 / 恒星形成区 + 3 个椭圆星系），全部布置在画面边缘与银盘上下方，靠 `depthTest:false` + `renderOrder -9..-7` 画在天穹之后、银河粒子之前，不遮主体；星云缓慢翻涌、暗星云压出前后层次、恒星形成区带微弱脉冲

- 行星之间是**真实相对半径**（地球=1：水星 0.383、金星 0.949、火星 0.532、木星 11.21、土星 9.45、天王星 4.01、海王星 3.88），统一乘 `PLANET_SCALE=0.13`、轨道乘 `ORBIT_SCALE=0.80`；太阳不按真实 109 倍画（否则整个系统会被吞掉）
- 13 颗天然卫星（`MOON_TABLE`：月球、火卫一二、木卫一~四、土卫二五六、天卫三四、海卫一），轨道半径与周期按真实数据压缩，真比例下只有亚像素，统一放大 1.9 倍并设 0.05 下限才看得见，绕母行星公转并跟随视角
- 背景里加了八颗真实存在的近邻恒星（比邻星 M5.5Ve 4.24 光年、南门二 G2V+K1V 4.37、巴纳德星 M4V 5.96、沃夫 359 M6Ve 7.86、天狼星 A1V+DA2 8.60、鲸鱼座 UV M5.5Ve 8.73、罗斯 154 M3.5Ve 9.69、天苑四 K2V 10.5），按光谱型上色（M 型偏红、K 型橙、A 型蓝白），每颗带一颗锐利的核心 + 柔晕 + HTML 名字标签，构图上是「天球内侧的一层」。
- 另加一层 2600 颗近景星（半径 260–580）：相机一转就明显滑过画面，视差很强；亮度压得很低，闪烁是两条不同频率的正弦相乘，所以忽明忽暗是不规则的，不是机械呼吸。 + `js/planetmat.js`
- 太阳：fbm 表面 + 临边增亮，`uSpin` 在着色器里旋转采样方向，所以自转是真的可见；外层两层辉光 Sprite 在贴近时自动淡出
- 8 颗行星按**真实相对半径**建模、按真实公转周期比例绕转（`speed = 0.42 * period^-0.62`），各自自转，土星环用手写 UV 径向映射
- 行星材质全部换成自绘 shader（`createPlanetMaterial`），不吃场景灯光，太阳方向按「行星自己 → 原点」每帧算好后塞进 `uSunDir`：
  - wrap 光照让**晨昏线有过渡带**，不是一刀切的硬边；晨昏线附近再混一层暖色，模拟低角度阳光被大气染红
  - 边缘变暗 `0.86 + 0.14*pow(dot(N,V),0.4)`，球体才不像贴了张平面图
  - 用贴图亮度梯度做**假凹凸**（`relief`），山脉/云带在斜光下有起伏
  - 冰面/海面窄高光（`pow(dot(N,H),64)`）、气体行星的大气边缘光（Fresnel × `rim`）
  - 参数按行星分别给：水星 `relief 0.9`、火星 `relief 0.6`、木星土星 `rim 0.15`、天王星海王星 `rim 0.24`
- 2200 点小行星带（压暗过，不会抢戏）、轨道线、环境光兜底
- 背景：一条倾斜大圆的**银河带** + 尘埃暗缝 + 少量 Hα 偏红的发射星云 + 极细星尘，再叠三层视差星点缓慢旋转流动

**地球** `js/scenes/earth.js` + `js/earthmat.js`
- 三层自绘 shader（不吃场景灯光，太阳方向由 `uSunDir` 驱动），太阳系里那颗小地球和地球场景共用同一套材质，俯冲时观感不会跳：
  - **地表**：4K Blue Marble 日面 + 夜面城市灯 + 海洋掩膜。日面先降饱和压暗，海洋按掩膜压成深靛蓝；高光用 `pow(dot(N,H),320)` 的窄反射，只在受光面的海面上出现；夜灯只落在陆地；临边按 `pow(1-dot(N,V),3.6)` 补一圈蓝色散射
  - **云层**：4096 云图取 **alpha 通道**当云量，受光面偏白、背光面压成冷灰，`alpha = a * (0.18 + 0.90*lit)`，所以晨昏线会从云上穿过去
  - **大气**：加法混合的 Fresnel 壳，受光侧更亮，形成一圈很薄的蓝色边缘光
- 23.4° 轴倾角，自转独立于手势：`root(手势四元数) → tilt(轴倾角) → earth`
- **360° 自由转动**：不把 yaw/pitch 直接拼成欧拉角（那样俯仰到 ±90° 就翻不过去），而是每帧取「手势增量」生成两个轴角四元数、`premultiply` 到 `root.quaternion` 上。这样横着拖多少圈、竖着翻多少圈都不会有死角和翻滚；俯仰角在太阳系/银河仍限 ±1.15 rad，只有地球放开
- **背景里的其他行星**：`BG_LIST` 里七颗行星（水星→海王星）外加一颗月亮（放在反方向，转过半圈还有东西可看）用同一套 `createPlanetMaterial`（和太阳系里的是同一个工厂），挂在一个叫 `skyPivot` 的组上；土星环是把 2048×125 的径向剖面贴图映射到 `RingGeometry` 的半径上（直接铺平面会变成一块板子）
- `skyPivot` 跟着手势转，但只有 `SKY_FOLLOW = 0.42` 的比例：近处的球转 1，远处的天转 0.42 → 转地球时背景行星会跟着平移、有视差感
- 背景穹顶换成**冷调深空**（靛蓝底 + 青蓝丝状云气 + 一条极淡的银河带），整体压到接近纯黑，只在太阳方向留一点暖色散射，让地球成为画面里最亮的物体。云气只在银道带附近出现（`bandCool` 遮罩），其余留干净的深空 —— 早先一整片紫褐色云会把地球衬成一团灰

**过渡** `js/main.js` —— 四条路径，靠 `T.mode` 区分：

| 路径 | mode | 时长 | 切场景 | 做了什么 |
| --- | --- | --- | --- | --- |
| 加载页 → 银河 | `intro` | 3.6s | 全程 galaxy | 时空隧道：`tunnelMat` 在「角度 × 深度」上铺噪声星场并沿深度做三次径向拖尾，隧道壁的星在飞、中心有核；0.58 附近一次白闪，同时银河从中心一个点长大（`galaxyGroup.scale` 0.06→1，粒子尺寸/亮度同步收窄，避免糊成白球） |
| 银河 → 太阳系 | `galaxyDive` | **9.5s** | 0.80 | 一镜到底的星际航行：速度曲线是分段积分的（0–2s 缓慢起步 → 2–6s 逐渐加速 → 6–8.2s 刹车 → 8.2–9.5s 收尾），`cinemaP(tt)` 把时间映射成「尺度进度」；镜头持续锁定猎户臂上的太阳（`sunR=52`），走廊里 620 颗掠过恒星 + 520 条**径向星芒拖尾**（`LineSegments`，长度随瞬时速度拉长）；星云与流沙在 3–10s 淡出（`st.nebFade`），银盘在最后 2s 压黑（`endFade`），只留那颗「目标星」，切镜瞬间用一次 0.34 的短闪光盖住尺度跳变；落地后 `st.solarArrive` 0.55→1 把整个太阳系稳稳拉出来，天穹与星场用 `st.clean` 收成纯黑深空 |
| 太阳系 → 地球 | `dive` | **7.0s** | 0.80 | 镜头从太阳系尺度持续推进、先快后慢（`dive = 1-(1-t)^2.6`）地放大到轨道上的那颗地球上，收尾机位固定在「向阳侧偏 65°」，FOV 60→38，末帧地球完整占满画面（3.05 倍半径），太阳辉光与轨道线随距离淡出。切场景是**无缝**的：交接前把俯冲末帧的「太阳方向 / 机位方向 / 地球自转角」打包成快照（`solar.getHandoff()`），切过去立刻喂给地球场景（`earth.adoptHandoff()`），同时让地球场景第一帧使用同样的 2.05 倍半径 + 38° 视场，外加泛光参数补间，所以没有白闪也没有尺寸跳变；落地后地球从特写缓缓拉回（`st.earthArrive` 0.60→1），轴倾角在这段时间里从 0 慢慢立到 23.4° |
| 地球 → 银河 | `emerge` | 3.1s | 0.38 | 镜头从地球快速后撤，地球缩成一颗光点（`st.earthOut` × 26 距离），同时隧道重新亮起；切换后银河**从中心一点长出来**（`st.intro` 0→1），完成「从小到大」 |
| 银河 → 地球 | `galaxyEarth` | 3.8s | 0.50 | 反向借用上面两条：先朝银盘里的太阳位俯冲直到粒子从镜头旁掠过，穿隧道，出隧道时地球已经推到眼前（`st.earthArrive` 0.62→1，即从 2.9 倍半径的位置继续贴近），隧道光条在 0.4 个进度内淡掉，不留「贴脸」的全屏贴图 |
| 地球 → 太阳系 | `earthSolar` | 3.3s | 0.44 | 地球后撤缩成亮点、隧道亮起，切换后太阳系**从太阳旁边拉开**（`st.solarArrive` 0.42→1）：第一帧太阳就在近处，随后整个系统向后退开。太阳本身的辉光球按相机距离收缩（`glowScale = clamp(camDist/74, 0.26, 1.10)`），否则贴近时那两个屏幕空间光球会把整帧刷白 |
| 太阳系 → 银河 | `solarGalaxy` | 3.5s | 0.46 | 太阳系按 `pow(k, 1.7)` 缓慢缩远（`st.solarArrive` 1→7），切换后银河从中心一点点长出来（`st.intro` 0→1），像从一团光里浮出一整个星系 |

后三条与 `emerge` 共用同一套「缩放穿越」语汇：起点缩成一个点或一团光 → 隧道亮起 → 目标从光里长大。标题文字在落地前（`tt` 0.52–0.80）淡掉，不会压在刚出现的星球/星核上。

另有兜底 `warp`（1.85s）：径向拉伸星线 + 冲击环 + 中心闪光，配压暗遮罩避免过曝。

启动时 `warmUp()` 会把三个场景各离屏渲染一帧：着色器编译、4K 贴图上传都提前到加载阶段，否则第一次切到地球那一帧要现场编译，表现就是「转场末尾卡一下」。

## 声音

整套音乐和音效都是 **Web Audio 现场合成**的（`js/audio.js`），不加载任何音频文件 —— 没有版权问题，也不需要额外素材，转场音效还能精确卡在切换点上。

**三条音乐床**，各自一条 14 秒一轮的和弦进行，场景切换时 1.6 秒交叉淡入淡出：

| 场景 | 和声进行 | 音色 |
| --- | --- | --- |
| 银河系 | Em9 → Cmaj7 → G6 → Dsus2 | 低频正弦垫 + 三角波和声 + 41 Hz 次低频 + 900 Hz 空气声，钟琴间隔 3.8–7.2 秒 |
| 太阳系 | Dmaj9 → Bm7 → Gmaj7 → Asus | 整体抬高、滤波开到 1.2 kHz，钟琴更密（2.6–5.2 秒），暖一些 |
| 地球 | Cmaj9 → Am9 → Fmaj7 → G6 | 最轻、留白最多，滤波 1.6 kHz，钟琴 4.2–8.2 秒 |

暖场的混响是用程序生成的脉冲响应（3.6 秒指数衰减噪声）喂给 `ConvolverNode`，不需要手工做 IR 文件。

**七条转场各有自己的音效**，长度和转场时长一致：

| 转场 | 声音做法 |
| --- | --- |
| `intro` 进入宇宙 | 带通噪声从 260 Hz 扫到 3.6 kHz（隧道壁的风） + 低频从 70 Hz 爬升 + 穿出隧道那一刻 96→28 Hz 的闷响 + 一串高音闪光 |
| `galaxyDive` 俯冲太阳系 | 60 Hz 起的长气声，扫频更慢更沉，切场景时一记重一点的闷响 |
| `dive` 俯冲地球 | 反过来：高频气声往下沉，只留一点铃，收尾是一记很轻的闷响 —— 不打断无缝交接 |
| `emerge` 升空回银河 | 由低到高的气流 + 四个音依次上扬的铃，像「浮出水面」 |
| `galaxyEarth` 银河直达地球 | 150 Hz 扫到 2.9 kHz 的长气声 + 低频从 52 Hz 抬起 + 切场景一记闷响 + 三个高音闪光 —— 比 `galaxyDive` 更长更「远」 |
| `earthSolar` 地球直达太阳系 | 气声从 240 Hz 往上铺开 + 四个音依次上扬的铃 + 低频 80→380 Hz 托底，落地时是「打开」而不是「撞进去」 |
| `solarGalaxy` 太阳系直达银河 | 气声由 520 Hz 往下落到 150 Hz + 低频 120→48 Hz 下沉 + 闷响 + 三个低一些的铃，像退到远处 |
| `warp` 兜底跃迁 | 噪声扫频 + 闷响 |

转场时音乐床会被 **duck** 到 55%（`duck` 节点在床和主输出之间，混响尾巴不跟着压），音效因此能站到前面；实测音效峰值比压下去的音乐床高 3 倍左右。

浏览器规定必须有用户手势才能出声，所以第一次点击/按键时才 `AudioContext.resume()`（`?auto=1` 自动进入也一样，任何一次点击都会唤醒）。右下角有一个三格跳动的按钮可以静音，静音时 `master` 平滑降到 0。

## 清晰度

**4x MSAA 走进整条后期链** `js/main.js`
`composer.renderTarget1/2.samples = 4`。之前只有 canvas 自己的 `antialias`，画面要过一遍 `EffectComposer`，抗锯齿其实是失效的 —— 星球边缘、土星环、轨道线全是硬锯齿。改成多采样渲染目标后，Bloom 的取源和 `OutputPass` 都在同一个 4x 采样缓冲里完成，边缘是真正被解析出来的，不是靠后期锐化假装。

**超采样** `js/main.js`
`MAX_DPR = min(devicePixelRatio, 2)`，`QUALITY_CEIL = 1.35`。1x 屏上机器够快时 `qualityScale` 会爬到 1.35，也就是按 1.35 倍分辨率渲染再交给浏览器下采样，星点和粒子会明显更「实」。掉帧时 `updateLod()` 会先把它降回来。

**纹理各向异性**
所有颜色贴图 `anisotropy = min(16, maxAnisotropy)`，行星掠射角上的条纹不会糊成一片。

**最后一道反锐化** `js/sharpen.js`
Bloom 会把所有东西揉软一圈，所以链路末尾加了一个 unsharp mask：取中心像素和上下左右四邻域的均值做差，按 0.40 的强度加回去，并且按亮度做掩膜（亮度低于 0.015 的暗部不参与，免得把噪点也提亮）。星点、行星边缘、土星环因此重新变「实」，而不是单纯靠加对比度。

## 流畅度

五件事决定了这套东西顺不顺：

**自适应分辨率** `js/main.js`
`MAX_DPR = min(devicePixelRatio, 2)`、`QUALITY_FLOOR = 0.72`、`QUALITY_CEIL = 1.35`。`updateLod()` 攒 48 帧算均值：超过 23.5ms 就把 `qualityScale` 降 0.14，低于 15.0ms 再升 0.07（升比降保守，避免来回抖）；单帧超过 250ms 的样本直接丢弃（切标签页回来那一帧不算数）。改分辨率时除了 `renderer.setPixelRatio` 和 `composer.setSize`，还要把每个材质里的 `uPixelRatio` 一起改，否则点精灵会忽大忽小。`?nolod=1` 可以关掉自适应（截图对比时用）。

**视角有惯性**
拖拽和手势的位移不再直接写进 `st.yaw/st.pitch`，而是先累加到 `panPending`，主循环每帧按 55ms 时间常数吃掉一部分、剩下的留到下一帧。松手时画面会自然滑一小段再停，鼠标和手势两种输入共用同一套平滑。

**推拉不硬切**
`st.dolly` 是访问器：输入写 `dollyTarget`，每帧用 85ms 时间常数向它靠拢。滚轮是离散的、掌心深度也会跳，直接赋给 `st.dolly` 会让画面一顿一顿。外部直接写 `st.dolly`（调试钩子、测试脚本）时 setter 会把目标值一起更新，所以 `U.st.dolly = 0.999` 这种写法依然有效。

**UI 不每帧写 DOM**
缩放条宽度和手势文案只在累计 0.08s 后写一次（约 12Hz）；场景标签会先比对字符串，位置和透明度没变就不碰样式，避免每帧强制重算。

**进场不卡第一帧**
`warmUp()` 在加载阶段把三个场景各离屏渲一帧，着色器编译和 4K 贴图上传都提前完成。

**转视角有纵深感** `js/main.js`
侧向扫视时按 yaw 的角速度给相机一点滚转（banking，上限约 4.3°），画面不再是「一块平面在平移」，而像绕着天体在飞。银河和太阳系的俯仰限制也从 ±1.15 放到 ±1.42，能绕到更高的角度看盘面。

## 手势

`js/gestures.js` 这一版换了三处：

**720p 采集** 摄像头请求 1280×720@30（原来 640×480）。手离远一点关键点就飘，分辨率是识别稳定度的第一道关。

**One Euro 滤波** 掌心和每个关键点都过一遍自适应低通：手静止时截止频率压到 1 Hz 左右（不抖），快速移动时随速度放宽（不拖影）。固定系数的指数平滑做不到两头兼顾 —— 系数大了抖、小了拖。

**手势防抖** 分类结果不直接生效：候选手势要连续成立 85ms 才切换；捏合还带迟滞（进 0.40 / 出 0.52），不会在阈值上反复跳。手短暂丢失（<220ms）时保持上一帧状态，缩放不会一卡一卡。

分类本身也换了判据：用「指尖到腕 / 近节到腕」的比值判手指伸展（比单纯比长度更抗透视），拇指按与食指根的横向张开度单独判断，`openness` 连续值再喂给缩放速度。

**骨骼叠层对齐**
摄像头预览是 4:3 的框、视频源是 16:9，`<video>` 用 `object-fit:cover` 会裁掉左右各 12.5%。之前 `<canvas>` 按视频原始分辨率画满整帧、再被 CSS 拉伸，坐标系和实际显示的画面差了一截，骨骼就整体往里挤。现在画布分辨率跟着面板实际显示尺寸（含 dpr）走，绘制时用同一套 cover 公式把归一化关键点映射进画布：
`s = max(cw/vw, ch/vh)`、`dw = vw*s`、`ox = (cw-dw)/2`（y 同理），点落在 `ox + p.x*dw`。窗口尺寸变化会重新同步画布并强制重画。合成关键点的像素级校验：palm(0.30,0.55) → (54,95)、tip(0.62,0.30) → (152,52)，画布上实际落笔包围盒 `[51,48,154,97]`，一致。

## 加载页

打开页面先看到的是「正在构筑星海」的进场页，背景换成 JWST 拍的**船底座星云**「宇宙悬崖」（Cosmic Cliffs, NGC 3324）——橙红的尘埃崖壁 + 深蓝星场，取自 NASA 影像库 `carina_nebula~large.jpg`。

它不是一张静止的图，而是四层叠出来的缓慢运动：
- **底图**：44 秒一轮的极慢推拉（1.03 → 1.15 倍，附带 ±0.5° 旋转），像镜头在星云里一点点飘
- **柔光层**：同一张图糊化 30px、`mix-blend-mode: screen`，68 秒反向漂移，给星云补一层会呼吸的辉光
- **暖光呼吸**：`.nebula-pulse` 一层暖色径向渐变，19 秒一次明暗
- **星尘**：Canvas 2D 画的浮尘 + 恒星，恒星有闪烁周期，最亮的 8% 带十字衍射（`js/loaderbg.js`）；开关页面时自动停掉

点「进入宇宙」后整层 0.9 秒淡出，接上**时空隧道**进场（见上面转场表）。系统开了「减少动态效果」时，推拉与浮尘会自动停成静帧。

## 已知取舍

- **行星之间是真实相对半径**（`js/scenes/solar.js` 的 `rEarth(ratio)`：水星 0.383、金星 0.949、地球 1、火星 0.532、木星 11.21、土星 9.45、天王星 4.01、海王星 3.88，统一乘 `PLANET_SCALE = 0.13`），
  轨道整体乘 `ORBIT_SCALE = 0.80`。太阳没有按真实半径画（真按 109 倍地球会把整个系统吞掉），这一点和「轨道压缩」一样是必然的取舍；想要行星更大就调 `PLANET_SCALE`，比例会一起变。
- 手势识别需要光线充足、手离摄像头 40–80cm，单手；捏合（pinch）目前只用于状态显示。
- 无摄像头时会自动进入鼠标模式，UI 右上角会显示红色「鼠标模式」。
